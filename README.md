# Technical Council — Glassmorphism design

This is a fresh Next.js implementation based on the approved light iOS-inspired/glassmorphism visual direction.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Pages

- `/` — Home
- `/events` — Events
- `/team` — Team
- `/clubs` — Clubs
- `/gallery` — Gallery
- `/contact` — Contact

## Important

The supplied design references contain some placeholder/generated people, statistics, phone numbers, social links and gallery imagery. Replace those with verified council data before publishing.

The existing source material identifies the site as a Next.js application and provides the council's title/description and core content. The current redesign intentionally avoids copying the old dark theme.

## Assets

Create:

- `public/logo.png`
- `public/gallery/*`

and replace the temporary CSS initials/placeholder gallery blocks with your actual council logo and photographs.
